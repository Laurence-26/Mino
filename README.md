# Mino

> Your personal finance companion.

Mino is a Flutter-based personal finance tracker that helps you log income and
expenses, see where your money goes, share group budgets with family or
flatmates, and export clean reports — all backed by Firebase.

The app is currently **free for all users**. Subscription scaffolding is wired
but gated behind a Firebase Remote Config flag (`paywall_enabled`) so
monetization can be flipped on later without an app release.

---

## Features

### Tracking
- **Income & expenses** with custom categories per user
- **Multi-currency** display via [`intl`](https://pub.dev/packages/intl)
- **Default categories** (Salary, Freelance, Groceries, Rent, …) that users can
  edit, rename, or replace
- **Receipt / description notes** on every transaction

### Visualizations
- **Dashboard** with net balance, income, and expenses summary
- **Reports** filterable by Week / Month / Quarter / Year / All Time
- **Analysis** screen with category breakdowns, percentages, and progress bars
- **Charts** powered by [`fl_chart`](https://pub.dev/packages/fl_chart)

### Groups
- Create or join shared budgets via invite code
- **Roles**: Admin, Editor, Viewer
- Per-group transaction history and financial summary

### Export
- **PDF** — fully localized reports with header, summary table, transaction
  table, page numbers
- **Excel** (`.xlsx`) — multi-sheet workbook with formatted totals
- **CSV** — UTF-8 with BOM so it opens correctly in Excel

### Auth & sync
- Firebase Auth: email/password, Google Sign-In, anonymous
- Real-time Firestore sync across devices
- Offline persistence enabled by default

### Other
- **Localization**: English, Kiswahili, Français
- **Push notifications** via Firebase Messaging
- **Local notifications** for reminders
- **Dark theme** throughout
- **Crashlytics** + **Analytics** for production telemetry

|---|---|

## Getting started

### Prerequisites
- Flutter SDK ≥ 3.10
- Dart SDK ≥ 3.10 (bundled with Flutter)
- Android Studio / Xcode for device deploys
- A Firebase project (the repo includes a `firebase_options.dart` pointing at
  the existing one)

### Install & run

```bash
flutter pub get
flutter run
```

That's it for local dev. The app boots with anonymous auth disabled by default
— sign in with email or Google.

### Firebase config

The Android `google-services.json` is committed (its API key is restricted by
SHA-1 + package name, so it isn't a secret). For iOS, drop your
`GoogleService-Info.plist` into `ios/Runner/` — it is **not** committed.

### Cloud Functions (optional)

```bash
cd functions
npm install
# Copy .env.example to .env and fill in your Twilio creds for OTP
firebase deploy --only functions
```

`functions/.env` is gitignored; the values are required only if you use the
OTP-via-SMS path.

## Localization

Strings live in `lib/110n/app_translations.dart` as three nested maps
(`en`, `sw`, `fr`). To add a new locale:

1. Add the language code to `AppTranslations.supportedLocales`.
2. Add a translation map for every existing key.
3. Add the locale to `MaterialApp.supportedLocales` (already wired via
   `localeProvider`).

To use a string in UI:

```dart
AppTranslations.of(context, 'addTransaction')
```

## Monetization (currently off)

The app ships with the full RevenueCat integration — entitlement
`mino Premium`, monthly/yearly/lifetime packages, hosted paywall, and Customer
Center — but every gate first checks the Remote Config flag
`paywall_enabled`.

**To switch the app to paid:**

1. Firebase Console → Remote Config → create boolean parameter
   `paywall_enabled`, default `false`.
2. Configure your RevenueCat dashboard (entitlement `mino Premium`, products,
   offering with three packages, paywall, Customer Center).
3. Swap the test API key in `lib/services/revenue_cat_service.dart` for your
   platform-specific production keys (`goog_…` and `appl_…`).
4. Flip `paywall_enabled` to `true` in the Firebase console — no app release
   needed.

## Repo layout notes

- **Branch model**: `main` is the trunk. Feature branches encouraged for
  anything non-trivial.

- **Secrets**: never commit `.env`, keystores, or production API keys. The
  `.gitignore` enforces this.
